Contains functions for various file or data conversion operations.

u4py.utils.convert.chunk_data(data: dict, save_folder: PathLike, chunksize: int = 1000, min_values: int = 5, compress: bool = True) → list

Chunks data into many smaller files with spanning a square of chunksize meters. Discards chunks with less than min_values.

Parameters:

  • data (dict) – The data loaded from a large unchunked h5 file.

  • save_folder (os.PathLike) – The folder where to store the smaller files.

  • chunksize (int, optional) – The chunksize to use for chunking, defaults to 1000

  • min_values (int, optional) – Minimum number of PSI points to be present in the chunk, defaults to 5

  • compress (bool, optional) – Whether to compress the data using gzip, defaults to True

Returns:

A list of chunks that have not been converted for some reason.

Return type:

list

u4py.utils.convert.reformat_inversion_results(results: dict, directions: list = ['U']) → dict

Takes the output of u4py.analyis.processing.invert_psi_dict() and converts it to a more intuitive format.

Parameters:

  • results (dict) – The input dictionary

  • directions (dict) – Which directions to use, defaults to [“U”,] which is the only reasonable component for most fits in this project

Returns:

The reformatted dictionary.

Return type:

dict

The output dictionary contains three arrays with the times for the original data “t”, the first fit “t_fit_1” and the second fit without outliers “t_fit_2”. Additionally, the result for each component is saved with its respective key [“U”, “E”, “W”]. These nested dictionaries contain the original data “y”, the first fit “y_fit_1” and the second fit without outliers “y_fit_2”, each with their corresponding error denoted by the suffix “_err”.
