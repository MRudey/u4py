Adds a small copyright string to the lower left of the plot.

  • text (str) – The text to add

  • ax (Axes) – The axis where to add the text.

u4py.plotting.formatting.map_style(ax: Axes, divisor: int = 0, grid: bool = True, crs: str = '')

Changes axis to be in a good format for a map.

Parameters:

  • ax (Axes) – The axis object containing the map.

  • divisor (int, optional) – The tick divisor, defaults to 0

  • grid (bool, optional) – Plot a red grid, defaults to True

  • crs (str, optional) – If given, adds the name of the coordinate system to the map, defaults to “”
