u4py.analysis.spatial.spatial_lookup(input_feature, points: GeoDataFrame, n: int = 1) → list[Tuple[float, int]]

Does a spatial lookup for the nearest point to all points in points. The data at input_feature has to have a valid format for creating a lookup Tree.

Arguments:
input_feature – A variable that contains some sort of x and y table

which can be converted to a lookup table with get_cKDTree()

points – The points to query.

Keyword Arguments:

n – The number of nearest neighbors (default: {1}).

Returns:

A list of n nearest neighbors for each point in the form of (distance, index)
