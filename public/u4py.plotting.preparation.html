u4py.plotting.preparation module

Contains functions to modify or reformat data for plotting. This module helps to declutter the u4py.plotting.plots() or u4py.plotting.axes() modules.

u4py.plotting.preparation.clean_points(points: ~numpy.ndarray, sigma: int = 2, fnc: ~typing.Callable = <scipy.stats._continuous_distns.norm_gen object>) → ndarray

Creates a numpy array for slicing that removes all outliers from the given points array. The outliers are defined by the standard deviation of the given statistical function which can be any scipy statistics function that supports standard deviations.

Parameters:

  • points (np.ndarray) – The array of points to clean

  • sigma (int, optional) – The amounts of standard deviations to use, defaults to 2

  • fnc (Callable, optional) – The statistical function to use, defaults to spstats.norm

Returns:

A numpy array that can be used to slice other arrays

Return type:

np.ndarray

u4py.plotting.preparation.get_timeseries_range(y: ndarray | dict, time: ndarray = None, key: str = 'y') → dict

Takes a time array and a component and calculates the data ranges for a nice plot.

Parameters:

  • y (dict) – The component array or dictionary

  • time (np.ndarray) – The input time array, defaults to None

Returns:

The data as [t_unique, y_med, y_95, y_68, y_32, y_5].

Return type:

dict

The input can be:

  • a multidimensional numpy array, e.g., a stack of stations

  • a dictionary from u4py.utils.convert.reformat_inversion_results().

The resulting dictionary contains only unique time steps and medians with quantiles at each of them.

u4py.plotting.preparation.make_gridded_data(converted_data: ndarray, chunk_size: int) → Tuple[ndarray, ndarray, tuple]

Converts the data given by convert_results_for_grid() into a nice gridded format for plotting with matplotlib’s imshow().

Parameters:

  • converted_data (np.ndarray) – The data in a single 2D matrix.

  • chunk_size (int) – Chunk size to generate X and Y Grid

Returns:

Linear and sinusoidal components each as array and the extend for plotting.

Return type:

Tuple[np.ndarray, np.ndarray, tuple]
