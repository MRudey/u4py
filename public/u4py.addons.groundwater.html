u4py.addons.groundwater module

Contains functions to work with groundwater data.

u4py.addons.groundwater.convert_GW_csv(file_path: PathLike) → dict

Converts a groundwater csv file provided by HLNUG to a dictionary.

Parameters:

file_path (os.PathLike) – Path to the csv file.

Returns:

Dictionary of data data organized in nested dictionaries.

Return type:

dict

The outer dictionary uses the station name as headers: station["NAME"]. This returns another dictionary containing the data:

“shortID”: Short ID given by HLNUG,
“gruwahID”: Grundwasser ID given by HLNUG,
“name”: The name of the station,
“easting”: Easting in EPSG:31467,
“northing”: Northing in EPSG:31467,
“time”: The time as a list of datetime objects,
“height”: The height of the water table above NN.
u4py.addons.groundwater.get_groundwater_data(file_path: PathLike) → dict

Loads data from pickled file.

Parameters:

file_path (os.PathLike) – Path to the pickle file

Returns:

The data as a dictionary with station names as keys.

Return type:

dict

The ground water data was supplied as a large textfile that was converted using convert_GW_csv() to a pickle file. The data is organized in nested dictionaries. The outer dictionary uses the station name as headers: station["NAME"]. This returns another dictionary containing the data:

“shortID”: Short ID given by HLNUG,
“gruwahID”: Grundwasser ID given by HLNUG,
“name”: The name of the station,
“easting”: Easting in EPSG:31467,
“northing”: Northing in EPSG:31467,
“time”: The time as a list of datetime objects,
“height”: The height of the water table above NN.
