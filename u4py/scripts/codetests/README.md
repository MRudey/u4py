# Codetests

Scripts used to test functionality of certain pieces of code.

- [byte_decoder.py](byte_decoder.py): Tests a custom code to decode a "well known binary" (WKB) representation of a geometry.
- [lookup_inv_results.py](lookup_inv_results.py): Tests a function that is supposed to find persistent scatterer results close to a given geometry.
- [seasonal_max.py](seasonal_max.py): Tests the superposition of two sine functions.
